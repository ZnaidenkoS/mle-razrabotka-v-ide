# DataFrameReporter

Инструмент для первичного анализа датафреймов pandas.

Класс DataFrameReporter помогает быстро оценить структуру и качество
данных без повторного написания кода для каждой таблицы.

## Возможности

Отчёт содержит:

- количество строк и столбцов;
- количество и долю дубликатов;
- сводную статистику;
- количество и долю пропущенных значений по всему датафрейму.

В конструкторе можно настроить формат чисел и процентов,
а также включить сводную статистику по всем столбцам.

## Структура проекта

- src/reporter.py — класс DataFrameReporter.
- main.py — загрузка данных и запуск отчёта.
- data/ — папка для датасетов.
- requirements.txt — список библиотек и их версий.

## Установка окружения

Команды выполняются из корня проекта.
Для macOS 

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```


## Подготовка данных

Скачайте датасет по ссылке:

https://code.s3.yandex.net/datasets/payments.csv

Поместите файл payments.csv в папку data/.
Датасет скачивается отдельно и не включён в коммиты проекта.

## Запуск

Из корня проекта с активированным виртуальным окружением выполните:

```bash
python3 main.py
```

Отчёт будет выведен в терминал.
